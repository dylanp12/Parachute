How It Works

Parachute runs as a sidecar container. Your agent has no direct internet access — all traffic flows through Parachute for inspection and control.

Security Features

Everything you need to run AI agents safely in production.

Egress Control

Domain whitelist with wildcard support. Only allow your agent to reach approved APIs and services.

Command Interception

Regex-based policy engine blocks dangerous commands and fork bombs. Shell wrapper unwrapping defeats evasion.

Human-in-the-Loop

Risky commands pause for human approval via web dashboard. Configurable timeout with persistent queue.

PII Detection

Blocks exfiltration of credit cards, AWS keys, private keys, and GitHub tokens in outbound traffic.

MCP Gateway

Native Model Context Protocol support. Inspect, policy-gate, and audit MCP tool calls between clients and servers.

Audit Logging

Structured JSON audit trail with correlation IDs. Prometheus metrics for monitoring. Full observability.

Try It in 30 Seconds

Clone, launch, and see every security feature in action with a live agent simulator.

Terminal 
# Clone and run the interactive demo
$ git clone https://github.com/dylanp12/parachute.git
$ cd parachute
$ docker compose -f docker-compose.demo.yml up --build

# Visit http://localhost:8080/dashboard/
# Username: admin | Password: demo

The demo includes an agent simulator that generates security events — blocked commands, approval requests, egress violations, and PII detection — so you can see every feature in action.
